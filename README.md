# QR Code MaR 📱

A premium QR code generator with animated space background. Generate, customize, and download QR codes instantly — all client-side, no data sent to any server.

![QR Code MaR](logo.png)

## ✨ Features

- 🌌 **Animated Space Background** — Starfield with nebulae and shooting stars
- 📊 **Multiple Data Types** — URL, Text, WiFi, Email
- 🎨 **8 Color Presets** — Classic, Midnight, Ocean, Purple, Emerald, Rose, Gold Dark, Inverted
- 🔲 **4 Dot Styles** — Square, Rounded, Circle, Diamond
- 🖼️ **Logo Overlay** — Drag & drop upload with adjustable size, padding, and shape
- 🔍 **Transparent Background** — PNG-only transparent background option
- 🏷️ **Custom Labels** — Add "Scan Me" or custom text below QR
- 📋 **Copy to Clipboard** — One-click copy QR as image
- 💾 **Export** — Download as PNG or SVG
- 🕐 **History** — Last 8 QR codes saved locally
- 📱 **Responsive** — Works on desktop and mobile
- ⚡ **Real-time Preview** — Auto-updates on any setting change

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom dark-mode design with glassmorphism
- **Vanilla JavaScript** — No frameworks
- **qrcode-generator** — QR code generation library (via CDN)
- **Canvas API** — QR rendering, logo overlay, and dot styles

## 🚀 Deploy

### Vercel (Recommended)

1. Push this repo to GitHub
2. Import at [vercel.com/new](https://vercel.com/new)
3. Deploy — Vercel auto-detects as static site

```bash
npx serve .
```
